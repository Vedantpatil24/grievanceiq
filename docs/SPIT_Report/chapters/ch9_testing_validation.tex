\chapter{Testing and Validation}

\section{Testing Strategy}
A comprehensive, multi-tiered verification and validation strategy was executed to guarantee software reliability, security compliance, algorithmic correctness, and UI robustness. The testing pipeline encompasses:
\begin{enumerate}
    \item \textbf{Unit Testing:} Verification of isolated mathematical formulas (Erlang-C, Little's Law), regular expression tokenizers, and NLP inference functions.
    \item \textbf{Integration Testing:} Verification of end-to-end data flows traversing HTTP request parsers, Pydantic schemas, SQLite transactions, and ReportLab PDF binary streaming.
    \item \textbf{Boundary and Security Testing:} Testing malformed inputs, SQL injection strings, oversized payloads, and unredacted PII patterns under the DPDP Act 2023.
    \item \textbf{Regression Automation:} Execution of a master automated testing harness (\texttt{test\_suite\_audit.py}) covering 48 discrete verification checks.
\end{enumerate}

\section{Defect Identification and Resolution History}
During rigorous integration testing, several engineering defects were identified and resolved:
\begin{enumerate}
    \item \textbf{Defect D-01: Voice Dictation Repeating Feedback Loop.}
    \textit{Symptom:} As the user spoke continuously, each new speech segment duplicated the previously recognized transcript, expanding the text area exponentially.
    \textit{Root Cause:} The \texttt{onresult} callback was appending cumulative results to the existing React state variable \texttt{description} via \texttt{setDescription(prev => prev + transcript)}.
    \textit{Fix:} Implemented a persistent \texttt{baseTextRef} anchor and isolated volatile session interim results, preventing repetitive re-concatenation.
    \item \textbf{Defect D-02: Failure to Redact Lowercase PAN Tokens.}
    \textit{Symptom:} Entering PAN \texttt{abcde1234f} left the token completely unmasked in the database.
    \textit{Root Cause:} The regular expression specified strict uppercase matching \texttt{[A-Z]\{5\}}.
    \textit{Fix:} Updated regex to \texttt{[A-Za-z]\{5\}\textbackslash d\{4\}[A-Za-z]} with \texttt{re.IGNORECASE}.
    \item \textbf{Defect D-03: Missing Key in Marathi Localization Dictionary.}
    \textit{Symptom:} React emitted console warnings when toggling language to Marathi on specific dialog modals.
    \textit{Root Cause:} Key \texttt{lang\_mr} was omitted from the Marathi translation mapping.
    \textit{Fix:} Synchronized dictionary keys across all three languages, restoring strict 222-key parity.
\end{enumerate}
