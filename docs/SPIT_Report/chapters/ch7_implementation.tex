\section{Frontend Implementation}
The client-side single-page application is implemented in React 18, utilizing the fast module bundling capabilities of Vite.
\begin{itemize}
    \item \textbf{Continuous Voice Dictation Module:} Implemented inside \texttt{SubmitComplaint.jsx}. It manages browser-level \texttt{webkitSpeechRecognition} event listeners. To prevent text loops, the component maintains a non-destructive reference \texttt{baseTextRef} for previously committed speech and appends volatile session transcripts without re-concatenating existing state.
    \item \textbf{Trilingual Localization Provider:} Centralized in \texttt{LanguageContext.jsx}. It exports a \texttt{useLanguage} hook providing active language state and a strict lookup dictionary containing exactly 222 localized keys across English (\texttt{en}), Hindi (\texttt{hi}), and Marathi (\texttt{mr}).
    \item \textbf{Interactive Operational Dashboards:} Developed using Tailwind CSS utility classes and Lucide icons, offering responsive grid layouts, SVG charts, and interactive What-If staffing sliders.
\end{itemize}

\section{Backend Implementation}
The backend application is orchestrated in \texttt{main.py} using FastAPI's asynchronous routing paradigm.
\begin{itemize}
    \item \textbf{Pydantic Data Contracts:} Strict type validation and JSON serialization schemas governing incoming grievance payloads (\texttt{ComplaintCreate}), user authentications (\texttt{UserLogin}), and resolution actions (\texttt{ResolutionMemo}).
    \item \textbf{DPDP Ingestion Middleware:} Case-insensitive regular expression substitution logic scrubs unredacted financial identifiers before persistent storage.
    \item \textbf{RESTful Routing Infrastructure:} Implements endpoints for grievance submission (\texttt{/api/complaints/submit}), status retrieval (\texttt{/api/complaints/\{id\}}), statutory receipt streaming (\texttt{/api/complaints/\{id\}/pdf}), and capacity analytics (\texttt{/api/analytics/queue-status}).
\end{itemize}

\section{Database Implementation}
The data persistence layer is managed through an optimized SQLite connection pool:
\begin{itemize}
    \item \textbf{WAL Mode Enforcement:} SQLite is initialized with \texttt{PRAGMA journal\_mode=WAL;} and \texttt{PRAGMA synchronous=NORMAL;}, ensuring concurrent read and write operations without database locking exceptions.
    \item \textbf{Relational Integrity:} Foreign keys are strictly enforced via \texttt{PRAGMA foreign\_keys=ON;}.
    \item \textbf{Atomic Transactions:} State updates are wrapped in Python context managers ensuring rollback upon unexpected runtime exceptions.
\end{itemize}

\section{Machine Learning Pipeline Implementation}
The autonomous categorization pipeline is trained on a dataset of 15,000 categorized Indian banking dispute records:
\begin{itemize}
    \item \textbf{Preprocessing \& Tokenization:} Lowercase conversion, removal of punctuation, and stop-word filtering across multilingual tokens.
    \item \textbf{Feature Extraction:} \texttt{TfidfVectorizer} with sublinear term-frequency scaling and n-gram ranges $(1, 2)$.
    \item \textbf{Classifier Training:} \texttt{MultinomialNB(alpha=0.1)}, producing high class-conditional probabilities for core banking dispute categories.
    \item \textbf{Persistence:} Serialized via \texttt{joblib.dump()} into \texttt{models/grievance\_model.joblib} for low-latency startup loading.
\end{itemize}

\section{Statutory PDF Receipt and Dynamic QR Implementation}
The PDF receipt generator is implemented using Python's \texttt{reportlab.pdfgen.canvas} engine:
\begin{itemize}
    \item Generates official institutional headers, metadata bounding boxes, and complaint summaries.
    \item Dynamically captures the incoming HTTP \texttt{request.base\_url} header, synthesizing an ISO/IEC 18004 compliant 2D QR matrix code that points to \texttt{\{base\_url\}/track?id=\{complaint\_id\}}.
    \item Streams generated PDF bytes directly through \texttt{StreamingResponse} with MIME type \texttt{application/pdf}.
\end{itemize}

\section{Implementation Challenges and Resolutions}
\begin{enumerate}
    \item \textbf{Challenge: Web Speech Loop Duplication in Continuous Mode.}
    \textit{Cause:} Browser speech recognition \texttt{onresult} handlers repeatedly deliver cumulative final strings alongside transient hypotheses, which simple \texttt{prev + text} concatenations duplicated indefinitely.
    \textit{Resolution:} Refactored the state pipeline using \texttt{baseTextRef} and segregated final session strings from interim tokens, delivering smooth, zero-latency streaming text.
    \item \textbf{Challenge: Incomplete DPDP Masking for Lowercase PAN Strings.}
    \textit{Cause:} Indian Permanent Account Numbers (e.g., \texttt{ABCDE1234F}) were previously checked via uppercase regex \texttt{[A-Z]\{5\}}, failing when customers entered lowercase characters (\texttt{abcde1234f}).
    \textit{Resolution:} Added case-insensitive matching (\texttt{re.IGNORECASE} or \texttt{[A-Za-z]\{5\}}), guaranteeing 100\% capture across all user input variations.
    \item \textbf{Challenge: Multilingual Context Key Parity Mismatch.}
    \textit{Cause:} English and Hindi dictionaries contained 222 localization keys, while Marathi contained 221, triggering missing key warnings during runtime rendering.
    \textit{Resolution:} Added missing \texttt{lang\_mr} key to all translation sets, establishing verified 222/222 key parity.
\end{enumerate}
